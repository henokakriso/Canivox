# Canivox — Smart Dog

Canivox is an intelligent robotic and AI-assisted dog project combining
autonomous robotics, computer vision, sensing, communication, and intelligent
decision-making.

It explores how an intelligent quadruped platform could assist with security,
monitoring, inspection, communication, and social-good applications. Canivox
is ARWE's exploration of embodied AI — moving intelligence from software
environments into physical systems capable of interacting with the real world.

**Core vision:** Create an intelligent physical companion and autonomous
robotic platform for practical real-world applications.

Part of [Project ARWE](https://github.com/henokakriso).
